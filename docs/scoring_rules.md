# Scoring Rules

## Group Stage

- Exact team in exact group position: 2 points.
- Full group order exactly correct: 5 point bonus.
- Correct best-third qualifier: 3 points.
- Best-third order is ignored.

## Knockout Matches

Base points by round:

| Stage | Base |
| --- | ---: |
| Round of 32 | 4 |
| Round of 16 | 6 |
| Quarterfinal | 10 |
| Semifinal | 16 |
| Third-place match | 14 |
| Final | 20 |

Winner-only mode:

- Correct advancing team: 1x base.
- Wrong advancing team: 0.

Score mode:

- Exact regulation score and correct advancing team: 2.5x base.
- Exact regulation score but wrong advancing team: 1.5x base.
- Correct advancing team but wrong score: 0.5x base.
- Wrong advancing team: 0.
